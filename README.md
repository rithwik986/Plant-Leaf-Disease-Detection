Movie Power BI Analysis

Overview
This project presents an interactive Power BI dashboard built using IMDB movie data. The dashboard provides insights into movie ratings, genres, popularity, revenue, and trends through visual analytics.

Features
- Analyze movie ratings and popularity
- Explore genre-wise movie distribution
- Revenue and budget analysis
- Interactive filters and slicers
- Visual representation of key movie trends
- Data-driven insights for better decision making

Tools & Technologies
- Power BI
- IMDB Dataset
- Data Visualization
- Data Analysis

Dashboard Insights
- Top-rated movies
- Most popular genres
- Revenue trends
- Movie count by genre
- Rating distribution analysis
